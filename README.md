## Versión de prueba para escáneres ELM327 (APK #15)

Descarga directa: [ANG-Car-prueba-vlinker.apk](https://github.com/nicoisuanii-coder/ang-car-apk-4/raw/main/ANG-Car-prueba-vlinker.apk)

Versión de prueba: escáneres ELM327 por Bluetooth (BLE y clásico). Lee VIN, datos en vivo y los módulos del auto (motor, ABS, airbag, carrocería, tablero…), y guarda un registro de la sesión para compartir (Conexión → "Compartir registro del escáner"). Aún no probada en un auto.
